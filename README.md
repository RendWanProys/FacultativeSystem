# ИС «Факультатив»

Клиент-серверная информационная система учета факультативных курсов, учебных групп, расписания пар и оценок.

## Стек и структура решения (`FacultativeSystem.slnx`)
- **FacultativeSystem** — настольный клиент WPF (MVVM), C#
- **FacultativeSystem.Api** — сервер ASP.NET Core Web API
- **FacultativeSystem.Core** — модели, сервисы бизнес-логики и слой работы с SQLite (`DatabaseService`, `FacultativeService`)
- **FacultativeSystem.Tests** — модульные и HTTP-интеграционные тесты (xUnit)
- **Курсовая_работа_ИС_Факультатив_WPF_SQLite.docx** — пояснительная записка курсовой работы

## Основные возможности
- **Роли**: Администратор, Преподаватель, Студент (авторизация по логину и паролю).
- **Администратор**: создание курсов (1 преподаватель на курс с автопоиском), управление учебными группами и их привязкой к курсам, управление учетными записями с автоподбором группы, выгрузка резервной копии БД.
- **Преподаватель**: выбор курса и «Группа курса», раздельное ведение студентов, пар («Поля факультета») и матрицы оценок за пары (`5`, `4`, `3`, `2`, `н/я`, `—`, `Зачёт`, `Незачёт`, `Сброс`) с необязательными заметками и итоговыми зачётами.
- **Студент**: просмотр курсов своей группы, таблицы оценок за пары и итоговых зачётов.

## Запуск
- Основной запуск: `Запуск_Факультатив.bat` (или решение `FacultativeSystem.slnx` в Visual Studio).
- Режим отладки (Dev): `Запуск_Dev.bat`.
